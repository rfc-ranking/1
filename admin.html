영상 연결 / 일괄 등록 사용법

한 경기: 선수·결과와 함께 영상 링크를 넣고 ‘경기 확정’을 누르세요. 다음 경기에도 같은 링크를 쓰려면 ‘고정’을 누르세요. 링크를 삭제하면 고정도 해제됩니다. 영상 없이도 기록할 수 있습니다.

여러 경기: ‘한꺼번에 기록하기’에서 날짜와 공통 영상 링크를 넣고, 실제 경기 순서대로 행을 추가하세요. ‘결과 미리보기’에서 점수·타이틀 여부를 확인한 다음 ‘전체 저장’을 누르세요. 점수는 위에서 아래 순서로 계산됩니다.

사용자는 경기 목록이나 선수별 경기 기록의 ‘▶ 경기 영상’ 버튼으로 유튜브를 엽니다. 기존 기록에는 관리자의 경기 기록 목록에서 ‘영상 연결’을 누르세요. 링크를 비우고 저장하면 연결만 삭제됩니다.

일반 영상·공유 링크(youtu.be)·라이브 링크를 지원합니다. 유튜브에서 공유 → 시작 시간을 설정한 링크를 붙여넣어도 됩니다. 별도 API 키는 필요 없습니다. 영상이 삭제되거나 비공개로 바뀌면 유튜브에서 재생할 수 없습니다.

상대별 시즌 누적 승리 점수

1·2승 100% → 3승 80% → 4승 60% → 5승 40% → 6승부터 20%

승자가 같은 상대에게 거둔 시즌 누적 승수로 계산합니다. 해당 경기의 승점과 패점 모두 현상금을 포함한 최종 계산값에 같은 배율을 적용하고 반올림합니다. 패배·무승부로 횟수는 초기화되지 않으며, 무승부 점수는 기존 계산을 유지합니다.

기존 시즌 승수도 포함하며 새로 기록하는 경기부터 적용합니다. 누적 승수는 기록 입력 시점을 기준으로 계산합니다. 과거 점수와 승·패·무 기록은 그대로 유지됩니다.
